# Código de la copia Practica4

`src/sir/Main.java` interpreta las opciones de consola y construye el
controlador. `sir/model` conserva parámetros, estados, individuos, resultados
y simulación; `sir/view` presenta tabla, resumen y gráfica; `sir/controller`
coordina y exporta CSV. Los comandos completos están en `../README.md`.
Esta copia no contiene el paquete `sir.io` ni el importador NetLogo de APE04.

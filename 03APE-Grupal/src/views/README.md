# Vista de APE03

`m_view.py` presenta las tablas, anima el historial del tamaño de cola y dibuja
seis gráficas estáticas mediante Matplotlib y NumPy. La imagen
`graficas_mm1.png` se escribe respecto al directorio de ejecución y se
reemplaza si existe. Con un escritorio se muestran ventanas; con
`MPLBACKEND=Agg` se pueden generar archivos sin ventanas, aunque la animación
no se visualiza. La vista no exporta CSV ni implementa clientes individuales.

# Código de APE03

Desde `03APE-Grupal`, ejecuta `python -m src.main`. El punto de entrada reúne
los escenarios de `models`, ejecuta SimPy mediante `controllers` y entrega los
resultados a `views`. No ejecutes `src/main.py` directamente: los imports usan
el paquete `src` desde la raíz de la práctica. Consulta el README principal
para dependencias, parámetros y limitaciones matemáticas existentes.

# Vistas Java

`VistaConsola` presenta parámetros, tabla y resumen. `GraficaSIR` dibuja las
series S/I/R con AWT/Swing y guarda un PNG mediante ImageIO. La opción
`--sin-grafica` evita abrir la ventana y conserva la exportación PNG. No se
requieren bibliotecas gráficas Maven externas. La ventana depende de que el
sistema tenga un escritorio disponible.

# Paquetes Java

`Main.java` interpreta `--semilla`, `--csv`, `--png`, `--sin-grafica` y
`--ayuda`, crea los objetos y llama al controlador. `model/` contiene estados,
individuos, parámetros y simulación; `controller/` coordina; `view/` presenta;
`io/` exporta. El directorio de fuentes Maven es `src/` y la entrada es
`sir.Main`. Ejecuta los comandos desde la raíz del proyecto, no desde aquí.

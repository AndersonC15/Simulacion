# NetLogo solo importa y representa

Abre modelo_sir_netlogo.nlogox con NetLogo 7.0.4. Conserva datos.nls, vista.nls, controlador.nls y java_simulado.csv juntos.

Al abrir se carga el principal y, si existe, java_referencia.csv. Ambos fueron generados por Java. Las cinco graficas representan las dos evoluciones y las comparaciones S/I/R. La referencia es opcional.

REINICIAR + ANIMAR reproduce filas; VER COMPLETO muestra todo. No se calcula ningun contagio en NetLogo. EXPORTAR INTERFAZ PNG guarda una imagen desde la aplicacion grafica, sin modificar los CSV.
